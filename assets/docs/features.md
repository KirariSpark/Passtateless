## 完全可配置的生成算法

**位置：主页 -> 生成设置 -> 生成预设 -> 自定义**

不同于其他无状态密码管理器采用固定、黑盒的密码生成逻辑，Passtateless 将密码生成的控制权完全交给了你。  
Passtateless 支持使用专用的生成脚本语言（DSL）来精确定义密码生成的每一个计算步骤。你可以自由组合哈希函数、密钥派生函数、字符截取、大小写转换、插入特定符号等操作。我们还内置了 `简易`、`复杂`、`六位数字` 等开箱即用的预设，可以满足大部分常规要求。

这意味着：
* **适应特殊要求**：无论目标网站对密码有什么奇葩的规则限制，你都能通过修改生成脚本适配。
* **绝对透明**：你确切地知道你的密码是如何一步步被计算出来的，没有隐藏的后门或不可预知的逻辑。

## 密码评估

**位置：密码强度**

在设置或评估主密码时，如何判断密码是否足够安全？Passtateless 为你提供了专业的答案。  
我们内置了业界知名的 `zxcvbn` 密码强度评估算法。  
与传统的“必须包含大小写字母和数字”这种表面化的规则不同，`zxcvbn` 通过模式匹配和概率计算，能够智能识别密码中的常见词汇、日期、键盘漫步模式等弱点，并给出真实破解时间估算。  
在应用底部的「密码强度」栏目中输入任意密码，即可直观地评估其强度，确保你的安全基石坚不可摧。
