## 开始使用

打开应用后会进入 **主页**。这是一个完全无状态的密码生成页面：它不保存、不记忆任何密码，只需在每次需要时输入几个信息，即可实时计算出可复现的密码。

## 填写信息

在主页依次填写三个输入：

- **用户名**：用于标识这个账号的字符串，可自行定义。
- **账号**：用于标识账号所在的平台、邮箱，或其他能标识一个账号或平台的内容。
- **主密码**：你的“万能钥匙”，必须牢记。

应用会把「用户名 `@` 账号」拼合成**种子字符串（seedString）**，并把主密码经哈希处理后作为 `master`，一起交给生成算法计算最终密码。

因为无状态，只要「用户名、账号、主密码」以及下方的生成设置保持不变，计算出的密码就完全一致。请在更换账号密码后，同步确保这些输入与注册时一致。

## 选择生成设置

**【生成设置】** 折叠面板决定密码如何被计算：

- **生成预设**：下拉选择内置预设——
  - **简易**：基于 PBKDF2 的生成流程。
  - **复杂**：基于 Argon2id 的更复杂生成流程。
  - **六位数字**：基于 Argon2id 生成六位纯数字密码。
  - **自定义**：使用生成脚本（DSL）完全自定义计算步骤。
- 选择 **自定义** 后会额外出现「配置生成规则」入口，点击即可进入 DSL 编辑器编写生成脚本。
- 根据所选预设，面板还会展示预设声明的额外输入（如密码长度、迭代次数、内存消耗），可按需调整。

## 后处理设置

在「主密码」输入下方有三个开关：**移除数字 / 移除字母 / 移除特殊字符**。它们会在生成之后对密码做一次后处理，用来临时适配某些网站的规则。请注意，这可能导致最终密码的长度发生变化。

## 查看或复制密码

填写完成后，通过下方两个按钮得到密码：

- **查看密码**：会先弹出确认对话框，确认后生成密码并在全屏页面展示，便于你阅读与记忆。
- **复制密码**：直接生成并复制到剪贴板。

由于不保存任何密码，每次需要密码时都请回到这里重新生成。更多关于生成脚本（DSL）的信息，可阅读 **配置生成器** 一文。
